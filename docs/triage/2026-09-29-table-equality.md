# 人人平等 + 全量文案拉齐：输光离席不再连累牌桌

**日期**: 2026-09-29

## 诉求
1. 玩家输光被迫退出，**不能影响其他真人继续玩**；
2. **不要有「谁是引擎、谁不是」的设定**——房间就是房间，开了之后大家权限一样、玩法一样；
3. 「已提交 · 等待确认」这类文案全部梳理干净。

## 根因
- **`eh_gt_leave` 对 `host_uid` 直接 `status='closed'`**：开桌人一输光/离席，整张桌散掉，别人跟着玩不成。
- 引擎持有者概念外露（「你来主持牌局」toast、isHost 门禁按钮）。
- 客人出牌后走私有状态「已提交 · 等待确认」，和别人看到的「轮到X/等待」两套语言。

## 改动

### 1. 人人平等（库 + 客户端）
- `eh_gt_leave`：删掉 host_uid→close 分支，**离席一律只腾座**；散桌只走 `eh_gt_close`（招募中取消）/ `eh_gt_reap`（无人 5min）/ 无真人自动解散。已部署线上。
- 引擎转移**静默**（内部细节，不 toast）。
- 招募区「一键补位/开始/解散」去掉 `isHost` 门，人人可点。

### 2. 主客同一套状态机（不露实现细节）
| 场景 | 文案 |
|---|---|
| 自己回合 | 轮到你 |
| 别人回合 | 轮到 X / X 思考中 |
| 已出手等快照 | **等待其他玩家**（与非我回合同一显示，不再「已提交/确认」） |
| 弃牌/全下 | 已弃牌 · 观战 / 已全下 · 等摊牌 |
| 等待发牌 / 人齐 | 等待发牌 / 等人入座 |
| 掉线 | 对手掉线 · 等待重连 |
| 出错/超时 | 出牌没成功，再试一次 |
| 出口 | 一律「返回房间」（收工/离桌/离开牌桌 全部废除） |

### 3. 回归
`journey-ui-consistency` 增「人人平等」契约：leave 不散桌、引擎静默、补位不按 isHost 门；文案契约禁「已提交/等待确认/引擎」。

**验证**: `journey-ui-consistency` / `bash scripts/ci-check.sh`
