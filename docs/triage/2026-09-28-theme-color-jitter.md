# 牌桌配色跟主题 + 打牌上下晃

**日期**: 2026-09-28

## 1. 写死配色脱主题
**现象**: 声音面板深蓝底+亮蓝钮、折叠片深蓝-青渐变、顶栏托管钮漏在统一规则外、日间台面字写死青绿/深金——浅紫等皮肤下丑且字看不清。
**方案**: `EhAudioMenu` 面板/开关全走 `--panel-solid`/`--ink`/`--accent`/`--line2`；折叠片与顶栏圆钮（含 `.gd-auto`/`.pk-auto`）统一 theme token + 日间 `--ink`；日间可读性压深改 `--ink`/`--sub`；警示红 `#ff5d6c`→`var(--magenta)`；底池/倍数金底走 `color-mix(amber, panel)`。

## 2. 打牌过程上下轻晃
**现象**: 对局中骨架上下一点点胀缩。
**根因**: ①回合横幅 `*TurnPulse` 带 `transform:scale(1.04)`，整条跟着胀；②手牌托盘/我方条/操作区用 `min-height`，牌数/文案变化时高度跟着变。
**方案**: 脉冲只亮边框去 scale；底部骨架改 `height` 锁死（横屏/小屏同步覆盖 `height`）。

**验证**: `journey-audio-mixer` / `visual-check-cards` / `journey-table-visual` + `bash scripts/ci-check.sh`

## 3. 头游后桌心留白
**现象**: 掼蛋有人头游后中央椭圆空着。
**根因**: 接风清 `lastPlay` → 桌心空态只空白/一行「新一圈」。
**方案**: 空桌心显「头游/二游」名次闪示；否则「新一圈 · XXX 领出」。

## 4. 战报页写死深蓝玻璃
**现象**: 结算卡深蓝底+混色字，浅紫主题下丑。
**方案**: `.gd-over-panel` 等整卡改 `--panel-solid`/`--ink`/`--sub`/`--line2`；名次徽章/残局条/按钮全走 theme token。

## 5. 命令弹层/低频功能
**现象**: 斜杠菜单分组标题+「今日还可玩」徽章很丑(非游戏命令也误挂); 时间胶囊/bgm库使用频次低。
**方案**: 菜单扁平化去分组去徽章(每日限制只留在三款开局门禁); 下线 /胶囊 /胶囊库 /bgm库 及实现。

## 6. 三款底部被裁
**现象**: 手牌/操作区底部显示不全, 被操作条遮挡。
**根因**: 手牌托盘锁高太矮(72/108px) < 实际内容(单排 ~150 / 掼蛋两排 ~190 / 德州预选+按钮 ~160), 牌底被后续操作条盖住。
**方案**: 按实际内容给 min-height(斗地主 150 / 掼蛋 190 / 操作区 100~140), 不再锁死截断; 横屏同步放宽。
**验证**: 几何探针三款 child-overflows 均 ≤0; visual-check-cards 操作区完整可见。

## 7. 跨端兼容 + 灵魂筹码累积
**现象**: iOS/安卓底部裁切、矮屏桌面被压到 ~44%; 玩家输完重开时灵魂筹码被清回 1000。
**方案**: 按屏高分级压底部栈(矮屏手牌 120/操作 88, 高屏 150/96); 我方条 72px 防溢出; resetMatch/startDeal 保留有筹码席(输光才补买入)。
**验证**: compat-audit PC/安卓/iOS 矮屏桌面占比 46%→49%+; poker 引擎/旅程/visual-check 全绿。

## 8. 顶栏毛玻璃压字 + 托管/离座策略
**现象**: 顶栏毛玻璃糊住标题; 挂机 3 轮才托管, 无两局离座。
**方案**: 顶栏改 panel-solid 实底+轻模糊, 标题对比拉满; MAX_MISS 3→2(两轮托管); _handsIdle≥2 自动 doEnterSpectator(两局离座), 本人有效操作清计数。

## 9. 全状态×全端口布局收口
**审计**: PC/安卓/iOS × 竖/横屏 × deal/bid/play 全矩阵; 溢出仅剩 .ddz-say 绝对定位气泡(预期悬浮)。
**方案**: 我方条改 height:auto + min-height(内容变化不裁); 审计忽略 absolute 浮层。
**结果**: full-states ALL_CLEAN; visual-check / table-visual / CI 全绿。
