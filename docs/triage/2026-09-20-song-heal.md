# 文字神曲失效

**日期**: 2026-09-20  
**现象**: 文字神曲点了像失效/没声/一直谱曲中。

**根因**:
1. 默认曲风是「清唱 acapella」，依赖**内网 TTS worker** 回写；公网/未部署 worker → 永远 pending，45s 后只标失败且点击仍只能重试。
2. AI 谱曲依赖 `eh-sing-cover` + `masters/manifest`；失败后卡片不可播。
3. `EH_CONFIG.songStyles` 远程覆盖若清空，`SONG_STYLES[0]` 会崩，发送/解析全挂。

**方案** (`app.js`):
- 默认曲风改为 `defaultSongSid()`：优先有母版的非清唱（DJ/Funk…）。
- 清唱发送后立刻 `playSongLegacy` 本地合成试听；超时/失败标 `local-ok`，点击本地可唱。
- 生成失败同样可本地试听；无 URL 时 `playSong` 必走 legacy。
- styles 空回退 `_BUILTIN_SONG_STYLES`；`parseSong`/`songHtml` 防崩。

**验证**: `node scripts/journey-song-heal.js` + ci-check  
**备注**: 清唱内网 worker 若要在公网可用，需部署 Edge/Worker 回写 `eh_messages`；前端已不依赖它才能出声。
