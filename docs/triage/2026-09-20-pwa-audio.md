# Echo 诊断 — PWA 游戏音效/音乐/语音异常

> 来源：主人 2026-09-20。「PWA下，游戏的音效、音乐和语音有bug，功能不正确」

## 现象
- PWA standalone：音效可能无声、BGM 不播或播了不恢复、TTS 不出声

## 根因
1. WebAudio `once:true` 解锁失败后不再重试
2. `Audio.play()` 在 PWA 被策略拦下，无手势重试
3. iOS PWA `speechSynthesis` 需 `resume()`，`onend` 易丢
4. `EhAudioBus` hold 泄漏可把 BGM 焊在静音
5. 进桌 `startGameBGM` 未先解锁

## 修复
- 持续手势监听 + `pageshow`/`visibilitychange` → `EhAudioUnlock.all()`
- `retryPlay` / `_ehNeedGesture` / `playsinline`
- TTS speak 前 resume + 下一 tick speak + failsafe
- Bus 45s watchdog `releaseAll`
- 进桌/开关 BGM 时 unlock

## 灵魂打牌说明
斗地主/掼蛋/德州 AI 为**本地启发式**（`js/games/*-ai.js`），**不用大模型**；不存在「模型失效」。台词为本地 QUIP 模板。外部 LLM 仅用于神曲翻唱（MiniMax Edge `eh-sing-cover`）等。

## 验证
`journey-pwa-audio.js` + ci-check
