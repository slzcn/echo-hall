# 登录与房间操作重复提交

## §1 现象
自动登录计时器与 Enter、快速双击建房／邀请码进入可在首个 await 前同时进入函数，产生重复认证、重复房间或重复加入请求。

## §2 稳定复现
让 `ensureAuth` 或账号解析延迟，在按钮 disabled 之前连续调用函数两次；旧实现两次都越过入口并发执行。

## §3 单一根因假设
防重入只依赖 await 之后才设置的按钮 disabled，函数入口没有同步 single-flight 锁。

## §4 不变量
同一登录、建房、邀请码加入操作完成前只允许一个请求；成功、失败、提前 return 均必须释放锁。

## §5 修复
三个函数入口同步设置独立 in-flight 标记，并用 finally 释放。

## §6 验证
`journey-submit-singleflight.js` 覆盖并发调用、失败释放和旧实现反证。

## §7 结果
待门禁回填。
