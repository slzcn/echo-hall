# Echo Bug 诊断单：游戏代码首屏无条件加载

## 1．用户旅程
只进入大厅／聊天 → 不应下载、解析从未使用的三套牌类 UI／引擎／联机代码；首次打开游戏时再加载且入口有明确等待态。

## 2．稳定复现
index 首屏 defer 加载全部 `js/games/*.js`，约 432KB 原始代码，即使用户从不玩游戏。

## 3．单一根因假设
游戏功能接入时直接放入静态脚本链，没有建立按能力动态加载器。

## 4．验证方法
新增旅程：首屏不含重型游戏脚本；打开对应游戏时按依赖顺序只加载一次；失败反馈并可重试；旧无条件加载必红。
