# Echo Bug 诊断单：空闲动画永久占用帧循环

## 1．用户旅程
桌面端移动鼠标显示拖尾 → 停止移动／切后台 → 动画应停止帧循环；再次移动后恢复。

## 2．稳定复现
`ambient-fx.js` 初始化后永久递归 `requestAnimationFrame(loop)`，空闲时仍更新六个节点。

## 3．单一根因假设
拖尾动画没有按 active／visibility 生命周期启停 rAF。

## 4．验证方法
新增纯逻辑旅程：首次无 rAF；移动后仅一个循环；空闲后停止；隐藏停止；恢复移动可重启；旧实现必红。

## 5．回归矩阵
- 桌面移动
- 静止
- 后台／前台
- reduced motion
- 触屏跳过

## 6．修复结果
拖尾改为按需启动单一 rAF；静止 600ms 或页面进入后台即停止并隐藏节点；再次移动可恢复。新增 `journey-cursor-trail-lifecycle.js`，覆盖空闲、活跃、静止、后台、恢复及旧永久循环反证。

## 7．发布验证
相关旅程与 `node --check js/ambient-fx.js` 已通过；待整批完整 CI、版本发布与线上复测。
