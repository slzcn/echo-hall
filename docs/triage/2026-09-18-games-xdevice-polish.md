# Echo 诊断 — 三游戏跨端 UI/交互/性能统一

> 来源：主人 2026-09-18。「三个游戏在不同终端下的界面风格、交互体验…一致性、美感度和交互体验，并提升游戏性能」

## 方案摘要
- **一致性**：table-shared 设计令牌（圆角/触控 44px/缓动/日间）；焦点环；减动态
- **交互**：斗地主双触选同点组（对齐掼蛋）；选中/提示语言统一
- **性能**：斗地主座位增量签名；德州几何缓存 + 既有两层签名；`contain` 限布局
- **跨端**：safe-area；宽屏 max-width；日/夜对比
