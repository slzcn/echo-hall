# Echo — 三游戏终端结构重排

> 主人: 不光丑，结构也不协调，按终端特点优化。

## 结构问题
手机竖屏招募：座位贴顶、中间大空洞、桌与「我」分离、操作区漂在底。

## 按终端重排
| 终端 | 策略 |
|------|------|
| 竖屏招募 | 桌心 ~150px、手牌带高度 0、操作区钉底、我方贴桌 |
| 竖屏对局 | felt 弹性吃中间，对手/我+手牌分列 |
| 横屏矮盒 | 矮高度清零硬 min-height |
| 桌面 | max-width 900 居中 |
| PWA | 顶部收敛，safe-area 仍生效 |
| 德州招募 | 椭圆 RX/RY 压扁、CY 上移 |

## 验证
`journey-terminal-layout.js`
