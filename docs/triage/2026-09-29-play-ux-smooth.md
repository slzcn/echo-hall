# 打牌交互丝滑化：进出一条路 + 提示词去黑话

**日期**: 2026-09-29

## 诉求
多人德州能打了，但交互不够顺：提示词不对、退出/加入步骤绕。目标——**每个人都能正常打牌；退出=返回房间；加入=点入口就进来**。

## 改动

### 1. 进出一条路
- **退出**：只留顶栏 `✕ 返回房间`（minimize，牌局后台继续；回来点牌桌卡）。收掉顶栏「离桌」和折叠片 `✕` 双按钮（与返回语义打架、文案还写「房主散桌/客人退席」）。
- **加入**：点牌桌卡/`/德州` 一条路 → 自动入座进桌；补「已入座 · 跟上这局 / 人齐自动开局」「回到牌桌」确认反馈。
- 结算页出口统一「返回房间」（原「收工/离桌/离开牌桌」混用）。

### 2. 提示词去黑话 / 对齐现架构
| 原 | 现 |
|---|---|
| 等房主发牌… | 等待发牌… |
| 等待玩家入座（掉线） | 对手掉线 |
| 等待行动 | 等对手行动 |
| 已提交 · 等待裁决 | 已提交 · 等待确认 |
| 你接管了牌桌引擎 | 你来主持牌局，继续打 |
| 只有引擎持有者能操作 | 只有主持牌局的玩家能操作 |
| 出牌未通过校验，请刷新后重试 | 出牌没成功，请再试一次 |
| 远客超时 · 暂由房主托管 | 对手超时 · 暂由系统代打 |
| 先收工当前牌局再开新的 | 这一局还没打完，先打完或返回房间后再开新的 |

### 3. 回归
`journey-table-chat` 增契约：三款无「离桌」双钮、加入有确认、用户可见文案无「等待裁决」。
