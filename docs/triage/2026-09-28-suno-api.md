# 接入 open.suno.cn 真唱歌

**日期**: 2026-09-28

## 结论
Suno API 调通。`eh-sing-gen` 首选 Suno(自定义歌词+曲风 tags)→ 轮询 task → 下载 m4a 回存 `eh-song`；积分不足/失败自动退 MiniMax→TTS。

## 实测
- 余额 60 积分; 一次生成返回 2 task_id, ~30s completed, mp3Url 实为 m4a(ISO-MP4)
- 桶 `eh-song` 只认 `Content-Type: audio/mpeg`(不看容器) → 仍按 audio/mpeg 上传, 浏览器嗅探可播
- 积分价 ~36/次(2 首); 试用耗尽后返回 402, 自动落 TTS(已验证)

## 部署
- secret: `SUNO_API_KEY` 已写入 Supabase(本地 `.secrets/suno-key`, 不进 git)
- `npx supabase functions deploy eh-sing-gen --no-verify-jwt`
- 探针: `SUNO_API_KEY=xxx node scripts/probe-suno-api.js`

## 调试: 唱词不进耳 / 整曲过长
**实测对比**
| 歌词模板 | 时长 | 词是否唱出 |
|---|---|---|
| [Verse]+[Chorus]×2 复读 | 87s | 前奏长, 易听成纯乐 |
| 纯词+[Chorus]+[Outro] 再复读 | 20~63s | 唱, 但拖 |
| **纯词两遍(无段落标签)** | **13s** | **唱, 两遍即收** |

**结论与修法**
1. 段落标签([Verse]/[Chorus]/[Outro])会拖长曲 → 改纯词 `\n` 两遍
2. tags 加 `short song, ends after two lines` 收尾
3. crop API 字段实测是 `crop_start_s`/`crop_end_s`(文档写 start_time 会 400) — 已对齐
4. aligned-lyrics 过滤 `[…]` 标签假词; 人声 0.4~18s 起止写入 chS/chE, 前端只播这一段
5. fullDur>22s 时裁到人声段; 正常 13~17s 不裁

**终验**: `回声厅里说句话` → 17.4s 文件, 播放窗 1.06~12.21s(≈11s 唱词)
