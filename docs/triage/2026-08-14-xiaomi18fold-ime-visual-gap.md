# 安卓折叠屏 PWA 输入框键盘顶沿错位

## §1 现象

- **设备**：安卓折叠屏（小米 18 Fold 展开态）
- **运行环境**：Android PWA，覆盖式软键盘，VirtualKeyboard API 不提供几何值
- **触发步骤**：进入 Echo → 打开私信或聊天室 → 聚焦输入框 → 弹出系统输入法
- **预期结果**：输入框容器底部贴在键盘顶沿，输入框完整可见。
- **实际结果**：私信输入框能上移但底部少数像素；聊天室输入框没有完整弹到键盘上方。
- **关键链路**：`innerHeight`／`visualViewport.height` 不变，`VK.boundingRect.height=0`，依赖无信号估算。

## §3 单一根因假设

**根因**：无信号兜底按可视屏高的 38％估算键盘高度，在该折叠屏的实际键盘高度上偏小，导致容器底沿仍落入键盘覆盖区；聊天室没有额外安全余量，因此表现更明显。

证据：真实 viewport 与 VK 均无变化时只能走估算；已有空 resize 修复已保留估算但仍出现固定少量错位。

## §4 修复方案

- 仅调整 `js/keyboard.js` 主聊天室与 `js/dm.js` 私信的无信号兜底系数：38％→39％。
- 真实 viewport/VK 信号路径不变；收键盘、旋转、折叠展开逻辑不变。
- 增加旅程测试，验证无信号路径保留更大安全余量，旧系数必红。
- 回滚：恢复两个文件中无信号估算系数，并同步回退版本号。
