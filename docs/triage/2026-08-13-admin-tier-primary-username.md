# 后台身份名单主标识改用用户名

## §1 现象
自定义身份名单目前以「昵称 @用户名」为主标识渲染。昵称可自由修改、可能重复、可为空，不利于识别唯一成员；用户名在注册时经 `eh-auth` 映射为唯一邮箱、`eh_accounts.username` 全表无重复无空，主人要求默认改用用户名做主标识。

## §2 稳定复现
1. 打开 `admin.html` → 身份类型 → 贵宾。
2. 名单里出现的第一行文字是昵称（如「热血狼」），用户名藏在后面 `@61女王`。
3. 昵称可改可重，仅靠视觉扫昵称容易认错人。

## §3 单一根因假设
`tierMemberHtml()` 在 `admin.html` 用 `<b>${昵称}</b> @${用户名}`，主副信息位置放反。改为主标识用户名，副标签昵称，UID 缩略保留。

## §4 影响面
仅后台 `admin.html` 名单渲染。后端 `/user-brief` 不动。

## §5 修法
- `tierMemberHtml(uid)`：
  - 有 `username` → 主标识 `@用户名`；`昵称` 作为暗色副标签在同行右侧，UID 换行小号仍保留。
  - 无 `username`（老账号缺失/反查失败） → 回退主标识为昵称，再退回 UID。
- 更新 `scripts/journey-admin-tier-members.js`：主断言由「先看到昵称」改为「先看到 @用户名」；补一条“缺 username 时用昵称兜底”，另一条“昵称用户名都缺时用 UID 兜底”。旧实现（先昵称）必须被抓红。

## §6 验证
- `node scripts/journey-admin-tier-members.js` 全绿；反证抓红。
- `bash scripts/ci-check.sh` 全绿。
- 部署后打开线上 `admin.html`，贵宾名单主行显示 `@61女王`，昵称作为副标签。
